What It Is

A client-facing demo app that puts Google Gemini AI into the role of an industry-specific receptionist. Prospects pick a niche, interact with a streaming AI persona, and edit the underlying system prompt live — seeing exactly how an AI receptionist behaves before committing to the full platform.

Built to shorten the sales cycle: instead of describing what an AI receptionist does, show it. Conversations stream in real time via WebSocket, ephemeral tokens keep the Gemini API key off the client, and system prompts are editable in-browser so prospects can customise the persona during the demo itself.

Architecture

Lightweight Express server purpose-built for live demos — no database, stateless by design.

  • Node.js + Express HTTP server
  • Google Gemini API for chat generation
  • WebSocket streaming — responses arrive token by token
  • Ephemeral token auth — Gemini API key stays server-side
  • Editable system prompts — hot-swapped per conversation
  • Single-file niche config (niches.js)
Stateless · No DB
🚀

How to Run

Up and running in under a minute. Requires a Google AI Studio API key.

# 1. Install dependencies
npm install

# 2. Set your Gemini API key
export GEMINI_API_KEY=your_key_here

# 3. Start the server
npm start

# 4. Open in browser
open http://localhost:3000
